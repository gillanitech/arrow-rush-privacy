## Publish with GitHub Pages
1. Create a public GitHub repository named `arrow-rush-privacy`.
2. Upload **the contents of this folder** to the repository root: index.html, style.css, arrow-rush-logo.png, .nojekyll and README.md. Do not upload a containing policy-site folder.
3. Open Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/(root)`, then Save. Wait for GitHub's deployment to finish.
5. Open the published HTTPS address shown by GitHub. Typical form: `https://YOUR-GITHUB-USERNAME.github.io/arrow-rush-privacy/`.
6. Use that real public address in Play Console → App content → Privacy policy. Set the same URL with the included release-build script; it embeds it in the app before signing.

Do not use the example URL until your own page is deployed. Test it signed out/on mobile. GitHub Pages' official documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
